## vX.Y.Z (YYYY-MM-DD): One sentence for users saying what this version brings

The heading line is fixed: `## v` + version + ` (date): ` + one sentence. The project website builds its changelog from it and splits releases at `## `, so nothing else in this file may use `## `.

Every release states all three, even when the answer is "no change".

### Gates
What changed in who can see or do what, or "No change".

### Warnings
What changed in warning text, format or placement, or "No change".

### Calculations
What changed in any amount, or "No change".
